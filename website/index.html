The idea

A language built to stay simple as it gets powerful.

Vayu combines approachable syntax with native compilation, static typing, object-oriented features, compiler optimization and a long-term ecosystem for software, games, systems and AI.

◈

Readable by default

Indentation-based, Python-inspired syntax keeps programs compact and easy to understand — with Vayu’s own types, structs and native path.

⚡

Native-first architecture

Vayu compiles to native code. Recursive fib is 13.5× Python today; a 50M loop is 188× Python, sitting next to g++ -O2.

⌁

Control when needed

Static types, structs, classes, inheritance and future resource-management features provide a path toward higher-level simplicity with lower-level control.

Language

Custom Vayu syntax. Not pseudocode.

Vayu source files use .vyu. The syntax is indentation-based and custom to the language: typed functions, structs, generic collections, classes, closures, exceptions and modules — taken from the live compiler, not simplified samples.

native.vyucustom · types · structs · recursion
# Custom Vayu — typed native source
struct Vec2:
    x: int
    y: int

def length_sq(v: Vec2) -> int:
    return v.x * v.x + v.y * v.y

def fib(n: int) -> int:
    if n < 2:
        return n
    return fib(n - 1) + fib(n - 2)

def total_of(lst: list) -> int:
    s = 0
    for x in lst:
        s = s + x
    return s

p = Vec2(x=3, y=4)
print(length_sq(p))
print(fib(10))
print(total_of([10, 20, 30]))

class Player:
    name: str
    health: int
    def __init__(self, name: str) -> None:
        self.name = name
        self.health = 100
    def damage(self, amount: int) -> None:
        self.health = self.health - amount
class Warrior(Player):
    rage: int
    def __init__(self, name: str) -> None:
        super().__init__(name)
        self.rage = 0

Native speed · right now

How fast Vayu is today.

Same programs, three runtimes: Vayu native, C++ compiled with g++ -O2, and CPython 3. These are the current numbers from the Vayu benchmark harness — not a projection.

Native Vayu is already in C++ territory on some workloads.

Recursive fib is within ~2× of g++ -O2 and 13.5× faster than Python. A tight 50 million iteration loop is 188× Python. OOP still has a gap — Phase 8 (escape analysis) is specifically aimed at closing it.
